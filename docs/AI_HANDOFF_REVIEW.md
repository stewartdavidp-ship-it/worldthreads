# AI research handoff: Brazil thesis challenge

6 October 2026. This is an agent-assisted workflow check, not an independent historian's endorsement.

A fresh Chrome investigation began with the deliberately weak premise: “The building was completed in 1826, so no teaching occurred before then.” The research question separated legal authorization, building readiness and actual teaching.

The exact generated brief was given to an independent agent. Its first return combined claims from different documents under one principal URL. Review caught that problem. The returned candidate was narrowed to the Arquivo Nacional retrospective account; its source type, date range, access limits and disagreement with Biblioteca Nacional remained explicit. The application brief now asks for separate candidates when claims rely on different documents.

The reviewed candidate was imported through Chrome and remained unreviewed, browser-local and worth no points. Reload preserved it. The player selected it on the evidence board, classified it as challenging the premise and explained that private teaching before full operation does not establish classes in 1816. Browser Back returned to the evidence stage and the saved decision remained available.

## What this established

The manual brief → independent assistant → source review → candidate import → evidence interpretation route is usable. A structurally valid return can still misrepresent which source supports which claim, so review remains necessary. The source discrepancy stays visible rather than becoming an invented resolution.

## What remains open

Contemporary class registers, contracts and payments were not located or examined in this pass. The retrospective account does not date the first lesson. No human participant or historian has reviewed this player's reasoning. The test did not earn badges or file a complete thesis; separate full-game suites cover those actions.
